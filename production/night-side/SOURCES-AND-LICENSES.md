# NIGHT SIDE — sources and production record

Original educational script and original synthesized harmonic score (no external music samples). The script is narrated by Kokoro-82M voice am_michael through VisionForge's optional speech endpoint. Caption cues use measured sentence-level synthesis boundaries, not speech-recognition word alignment. No word-accuracy claim is made.

Footage: NASA/MSFC Marshall Night Stars (James Bilbrey, Joe Kuner); NASA/GSFC GOLD Resources: ISS Airglow (Joy Ng and credited production team); NASA/GSFC Lights of Human Activity Shine in NASA's Image of Earth at Night (Kathryn Mersmann, Joshua Stevens, Mike Carlowicz, Kate Ramsayer, Miguel Roman); NASA/JSC Five Minutes in Orbit; NASA/JSC ISS Expedition42 time lapse.

SOURCES.json records source/download URLs, credit, byte counts and SHA256. NASA factual educational use is subject to NASA media guidelines, third-party exceptions and no implied endorsement: https://www.nasa.gov/nasa-brand-center/images-and-media/ . NASA is not claimed to endorse VisionForge. Night-lights footage is satellite-composite animation; the script identifies it as such. No Pexels footage is used.

Kokoro-ONNX inference software: MIT. Kokoro-82M model: Apache2.0. Production-only models are not bundled owner requirements. DejaVu Sans font license accompanies this project. Original script/music/title graphics may be used with this project. This document is a provenance record, not a claim that every NASA asset is universally public domain.

Final assembly, captions, audio mixing, effects, preview and MP4 export occur through the actual Electron application. External FFmpeg generates source music/converts source narration and validates output; it does not assemble the final film. Production worker loads local models with ORT_DISABLE_TELEMETRY=1 set before runtime initialization, offline Hugging Face settings and telemetry API disabled. No service key is needed for this local demonstration.

This demonstrates the tested workflow on Linux. Windows10/11 installer/runtime acceptance remains outstanding. It is not a final application release.
