VisionForge runtime dependency notices

License texts are copied verbatim from installed package versions recorded in runtime-dependencies.json. This conservative set includes non-development lockfile dependencies even when a package is not retained by bundling. Electron and Chromium license notices are supplied beside the executable by electron-builder. DejaVu font notices are in resources/fonts. FFmpeg/FFprobe GPL text and release-blocking source status are in resources/tools/win-x64. This directory is not a complete GPL corresponding-source archive or a legal approval.
